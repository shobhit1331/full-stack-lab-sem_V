# Full Stack Development Lab - Practical Test, Set B

Two small practicals, each in its own folder with its own README.

| Folder | What it is | Run |
|---|---|---|
| [`b1-jwt-auth-api`](./b1-jwt-auth-api) | Express API: register, login, protected profile route using JWT | `npm install && npm start` |
| [`b2-shopping-cart`](./b2-shopping-cart) | React cart with quantity controls and an automatic discount | `npm install && npm run dev` |

Needs Node 18 or newer. Each folder has tests: run `npm test` inside it.
